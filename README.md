# 🎓 Student Grade Calculator (Java)

A console-based Java application that manages student records and calculates academic performance including total marks, percentage, grade, and result. It also supports multiple students with ranking and file storage.

---

## 🚀 Features

- Add multiple students with dynamic subjects
- Calculate total marks and percentage
- Automatic grade assignment (A+, A, B, C, etc.)
- Pass/Fail evaluation
- Search student by ID
- Display rank list based on percentage
- Identify topper student
- File storage (save & load student data)
- Menu-driven system

---

## 🛠️ Technologies Used

- Java (Core)

- Collections Framework
